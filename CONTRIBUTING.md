# Contributing

Thanks for your interest in improving Agentic Code Reviewer.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused and easy to review.
4. Add or update tests when behavior changes.
5. Run the relevant build/tests locally.
6. Open a clear pull request with a concise summary.

## Local development

```bash
npm install
npm run build
npm test
```

## Code expectations

- Prefer clear, maintainable TypeScript.
- Keep analyzers deterministic and explainable.
- Avoid adding secrets to the repo.
- Document behavior changes in the README or docs when needed.

## Reporting issues

Open a GitHub issue with:

- the problem description
- reproduction steps
- expected behavior
- actual behavior
- relevant logs or snippets
